An interactive portal hosted on **GitHub Pages** designed to visualize the performance, tracking, and technical analysis of financial investments, with a primary focus on the semiconductor (NVDA, TXN) and healthcare sectors via eToro.

This repository contains the presentation layer (frontend) that exposes market *insights*, consuming data generated by the backend quantitative analysis and artificial intelligence engine.

Live site: https://asuskf.github.io/asuskf-invest.github.io/

---

# 🎯 Project Objective

To provide a public, static, and highly optimized interface for:
- 📊 **Data Visualization:** Displaying key metrics and technical analysis of the investment portfolio.
- 🌐 **Accessibility:** Serving as a fast, responsive personal dashboard accessible from any device.
- 🔎 **Discoverability:** Readable by search engines and AI assistants (SEO + GEO) without running JavaScript.
- 🔌 **Decoupling:** Keeping the presentation layer strictly separated from business logic and data extraction.

---

# 💻 Technology Stack

As a static site implementation (`.github.io`), the repository is kept lightweight and fast:

- **Hosting & Deployment:** GitHub Pages
- **Frontend:** HTML5, CSS3, vanilla JavaScript (no build step)
- **Brand:** design tokens (`--ak-*`) and self-hosted fonts from the `brand-guidelines-investing-asuskf` skill
- **SEO / GEO:** schema.org JSON-LD, Open Graph, `sitemap.xml`, `llms.txt`

# 🔄 Monthly update checklist

1. **Returns:** edit the rows of the `<table id="matriz">` in `index.html` (newest year on top; empty cells for future months).
   `main.js` recalculates the heatmap colors, YTD, cumulative return, and the "Datos hasta" date from that table.
2. **Fallback figures for crawlers:** update the static text of `data-kpi="total"`, `data-kpi="ytd"`, and `data-kpi="updated"`
   so bots that don't run JavaScript see the same numbers as visitors.
3. **Videos:** in each `[data-video-id]` card, update the video id, link, thumbnail, title, description, `<time datetime>`,
   and `data-duration` (ISO 8601, e.g. `PT8M50S`). The `VideoObject` structured data is generated from the card.
4. **Freshness:** set `dateModified` (JSON-LD in `<head>`) and `<lastmod>` in `sitemap.xml` to the update date.
5. **FAQ:** if you edit an answer, edit the matching `FAQPage` entry in the `<head>` too.

# 📈 Analytics / SEM

Every call to action has a `data-cta` attribute. If GA4 (`gtag`) or Google Tag Manager (`dataLayer`) is added, `main.js`
sends a `cta_click` event (`cta_id`, `link_url`) that can be marked as a conversion for Google Ads. Without analytics it does nothing.
