An interactive portal hosted on **GitHub Pages** designed to visualize the performance, tracking, and technical analysis of financial investments, with a primary focus on the semiconductor (NVDA, TXN) and healthcare sectors via eToro.

This repository contains the presentation layer (frontend) that exposes market *insights*, consuming data generated by the backend quantitative analysis and artificial intelligence engine.

---

# 🎯 Project Objective

To provide a public, static, and highly optimized interface for:
- 📊 **Data Visualization:** Displaying key metrics and technical analysis of the investment portfolio.
- 🌐 **Accessibility:** Serving as a fast, responsive personal dashboard accessible from any device.
- 🔌 **Decoupling:** Keeping the presentation layer strictly separated from business logic and data extraction.

---

# 💻 Technology Stack

As a static site implementation (`.github.io`), the repository is kept lightweight and fast:

- **Hosting & Deployment:** GitHub Pages
- **Frontend:** HTML5, CSS3, JavaScript 
- **Visualization:** Web charting libraries for rendering technical indicators
- **Data Source:** Consumption of static files (JSON/CSV) exported daily by the analysis pipeline.
